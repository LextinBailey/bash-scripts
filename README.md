# Bash Scripts

A collection of beginner-friendly Bash scripting projects focused on Linux automation and systems administration tasks.

## 📜 Scripts Included

### 1. 01_create_structure.sh

Creates a simple project folder structure with `src`, `docs`, and `tests` directories.

#### How to Run

```bash
./01_create_structure.sh
```

#### Example Output

```bash
Creating folders...
Done.
```

#### Concepts Demonstrated

- Shebang (`#!/bin/bash`)
- Using `echo` for terminal output
- Creating directories with `mkdir`
- Using the `-p` flag to create parent directories safely
- Basic Bash script structure
